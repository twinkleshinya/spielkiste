# 自动混音与验收

先保证玩家听得清预警、蓄力、释放、接触、角色发声，再放环境、音乐、脚步和碎屑。目标是节奏和层次，不是把所有素材拉到同样响。

## 处理

- 新视频固定数字静音原视频音轨；播放声全部来自指定目录。历史版本编辑保留其原音设置并记录；工作台不再提供原声混入开关。不会从视频偷用吼叫或生成新音效填补素材。
- 按源 RMS/峰值和角色分层设增益，角色吼叫与关键动作作为前景保护，音乐/环境/细节在前景处做平滑避让。重叠duck取统一包络，避免多次相乘造成抽吸。重复混音不能不断衰减或伸长片段。
- 先按全音频/仅音效/仅音乐及静音状态确定实际可听贴片，再计算避让、密度和距离余量。输出模式排除的声音不能触发避让或改变实际输出的电平；保留清单记录供编辑。
- 读取每条事件的 `distance(range/confidence/evidence)` 与 `importance`。画面可靠时按实际发声位置给近/中/远三档减益；远处Boss的吼叫、捶胸较轻，投到玩家身旁的石块命中按近处落点处理，不跟施法者一起压低。不能凭巨大角色占屏比例编造米数；缺证据或置信度不足时电平中性，报告待复核。UI、音乐与环境底床豁免角色距离。
- 主次与远近分别判断：吼叫、预警、蓄力和主要命中保有声音主体与可读性，同时接受距离衰减；碎石、衣物、普通脚步及次层更靠后，不能因category=impact就全部保护为前景。模型importance与声音主体冲突时，真实发声/预警/蓄力优先；真正关键落地可按key处理。具体减益读取 WorkflowPolicy，不复制到多处。
- 先控制声音密度，再做电平：Boss主线连续动作的前景峰值并发超过6层时标记待复核，优先删除或静音重复的texture/tail/foley，保留吼叫、蓄势、每次真实接触和关键命中。不要靠把所有主线一起压低来解决拥挤。
- 专用API的纯混音操作不调用模型，不换素材或重裁声音主体，保留原 sourceOffset/duration/fade，包括有效但较长的人工fade。日常工作台已合并为固定自动流程，无独立混音模式选择。已有预览与清单一致时直接播放；更新预览按保存的贴片和电平渲染，不能因补测元数据而悄悄取整、缩短或关闭贴片，区间无效需报告。已保留版本的编辑另存副本，丢失的原预览不能在原run上静默重做。重新分析/选材与重新裁剪必须由用户明确要求，不能夹带在混音或技能验证里。
- 不把整段长源文件当成尾音。先按选材技能确定源区间，再给边缘短fade；未锁定贴片自动处理，已锁定人工编辑保留并提示检查。
- 静音/删除与其他人工编辑先暂存，点击“更新视频预览”才批量另存视频：渲染时同时检查event.muted和placement.enabled；被静音点位不再触发音乐避让，也不计作模型漏配。其余音效保留源区间、fade和gain；仅重新计算实际启用声音的避让与总线。零贴片可正常输出静音视频。已有预览画面复用编码以减少等待；本地完成后自动切换，失败报告原因，保留暂存编辑和修改前预览供重试。
- 无新增混响、无变速、无变调。空间感来自源素材的尾音和前后层次；若用户另要求混响，作为明确的新配置设计，不能默默加进本标准。
- 已保存贴片的 `perspective.distanceGainDb` 记录电平里包含的距离减益；普通预览保留，不再次扣减。锁定手工设置保留，不把未处理锁定项宣称为空间混音已完成。编辑导出包含事件距离依据和各贴片实际减益。
- 主总线先测量再处理：含可靠距离记录时，以去距离减益参考能量和实际能量之差预留响度空间，使用线性增益与真峰约束，避免全远景被归一回近景响度。−20 LUFS为近景基准，远景有效目标可以更低；未知距离历史清单保持原两遍响度流程。有效目标、距离余量、实际处理方式与渲染后实测读mix-report，不把低于−20一律当失败。文件输出48kHz/24bit立体声WAV，预览H.264/AAC。

## 客观检查和听感检查

`workflow-report.json` 必须涵盖实际模型/配置版本、阶段完成或复用、源路径、音频/视频范围、fade、差异备选、已列动作覆盖、音乐/环境缺口、发声复核、持续蓄力声体冲突、实测响度与预览revision。人工保存或仅重混音的当次用量不继承旧token；失效的旧实测响度不能用于新编辑的清单。

| 结果 | 处理 |
| --- | --- |
| 路径越界、源区间无效、未锁定裁剪无fade | 修正后重新渲染；不得标交付通过 |
| Gemini部分失败、无合适素材、未测量备选、锁定零fade | 可给待复核预览，明确具体缺口 |
| 全部自动检查通过 | 仍需人工试听，不能把客观通过等同最终质量验收 |

试听至少覆盖近远声源、靠近玩家的落点、预警/蓄力/吼叫/连续接触/UI/音乐进退和所有裁剪边缘。检查远处脚步是否比主要动作还近、细碎声是否抢重点、奇怪啾声、原素材内升调、音乐抢前景、突断、重复叠加。无试听工具时只报告客观测量，不声称已经听过。

比较版本时同时看点位、所用素材与区间、混音和实际请求耗时/token；重混音复用模型结果不能拿其短耗时冒充全流程速度。对照原版只读，不覆盖。API失败没有usage就报告缺失，不按0token推算。
