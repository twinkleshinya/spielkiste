# 本地选材与声音段落

新选材先执行项目的 `excludedLibraryPaths` 和 `excludedKeywords` 强制排除，再进行名称/路径加权。禁用词在文件名和路径中按 NFKC 忽略大小写作字面包含，不自动扩展别名；过滤覆盖候选准备、Gemini 音频请求、模型错误/失联后的规则回退和贴片生成。不得把旧候选、previousAssetId 或优先权重作为绕过方式。已有贴片不因新增规则自动删除或重选；新换用被禁素材须拒绝。

让动作、声音主体、材质和发声长度同时匹配；所有播放内容来自用户选择的音效/音乐目录。

## 检索和选择

1. 索引先记录路径/名称，候选才解码、探测起音/电平/时长。优先目录配置 `libraryPreferences` 跟随任务保存：总库仍全范围检索，指定路径内同样合适的素材获得有界加分；未相关的素材不能因权重进入候选，重叠目录取最高权重，不累计。候选理由记录路径与权重，Gemini 接收 `pathPreference`，按实际声音适配决定；路径权重不影响音量。大库不得逐文件 FFprobe。沿用 `AudioLibraryIndexer` 的缓存和进度。
2. 用 Gemini 点位的 actor、phase、query、description 检索英文/中文同义词，如施法 cast/magic、蓄力 charge、吼叫 roar。名称是相关性线索：收势带 start 或准备带 end 降权/标疑点，但有实际片段依据时可用；不能仅因一个词就删掉最合适的声音。
3. 对短名单合并同一录音的编号变体，并比较时长、频带、能量包络、谱重心。备选优先呈现不同材质/重量/瞬态/衰减；不足时少给。匹配不佳的薄啾声不能仅为多样性凑入。Boss大型接触默认只保留主体冲击，最多增加一个能证明有材质意义的尾音或纹理；连续接触之间优先换节奏和留白，不重复堆相同装饰层。
4. Gemini听候选片段，结合画面意图复核关键/疑难事件、UI、音乐。请求保留event.query与layerQuery，不能只传画面description而丢掉想表现的声音。标准范围为 selective；其他清晰普通动作保留规则选择。保存已请求音频、选择/拒绝/回退依据；未听的文件不能称为听过。
5. 选材后再去相似，当前选用项放首位，同一动作的多个层不重复叠同一文件。人工锁定项不被自动选材覆盖。重新选材生成新版本，保留原版。

普通短吼叫要求不等于“只能纯叫声、完全无接触”，不得自行扩大排他范围；只有用户明确限定时才严格拒绝范围外成分。长源录音可裁出一个合适发声，不能只看整文件比动作长就拒绝。仅音效模式将生成内容、距离与重要性传给音频判断，并排除已被音频分析确认混有音乐的自动候选；保留待试听备选。普通迈步单层表达，不因描述出现地面就自动叠重型碎石尾音。

用户认可上一版时，素材及 sourceOffset/duration/fade 也是被认可结果的一部分。打包技能、更新工作流、生成预览或纯混音不授权更换它们；只有明确“重新选材/重新剪辑”才触发对应判断。点击“已选用”不能重算区间。搜索只返回候选，点击其他候选“选用”属于人工编辑，先暂存；点击“更新视频预览”后才保存子版本并更新视频，原版保留。

工作台选材范围固定，不给用户切换全量/局部模型选材。每层音效可单独静音/恢复/删除，和替换、时间、音量、区间编辑统一先暂存，只有点击“更新视频预览”才批量生成新版本；没有选材请求，不补选被删素材，不把被删层自动填回来。整点位静音优先于层enabled，恢复点位时仍保留各层原状态。替换不重新调用模型，也不改变未选中层；草稿恢复与失败重试遵守主流程技能。

持续蓄力先判断声体是否连续，再看charge/loop标签。需要平滑持续声却选中描述为多次脉冲、脆裂或连发的素材时，工作台标为待试听并在质量报告列出冲突，不擅自换掉已选素材。这个检查依据候选片段描述，不能证明整段音频的连续性；明确需要节奏脉冲的画面/声音意图可以使用脉冲素材，不设统一禁用。

## 源音频剪辑

按动作区间 + 一个声音主体 + 有意义的短释放取片段。完整文件可能含多次吼叫，不等于一个完整发声。也不能把声音一律裁成 .1秒或固定事件长。

- 角色发声先做本地有界提案，再让Gemini听原素材片段返回 sourceStart/bodyEnd/releaseEnd、理由和置信度；仅接受素材/视频边界内、已发送样本内的有效区间。限制由 WorkflowPolicy 和 GeminiSourceEditor 执行。
- 例：嘴部动作 .7秒，8秒源文件有三次吼叫。先定位其中一次匹配的主体和短尾，不能由时长信息直接编造确定结束点；不能把三次全播。模型未给有效范围时使用本地有界版本并标待复核。
- 单次接触保留自然尾音到安全边界；环境/音乐可循环并平滑进退，移动收势较短。不要用长尾遮住下一次预警。
- 裁剪处默认5ms淡入、80ms淡出，短于两者总长时按比例缩短。锁定人工零fade只提示，不暗改。
- 不新增变速、移调或音高自动化。源录音本来升调，直接播放仍会升调；不合画面时换素材/段落，不能称为处理器升调。

交付 `selection-report.json`、`source-edit-report.json` 和贴片的 sourceOffset/duration/sourceEdit.basis。失败时写明 fallback，既不能假称Gemini已确认，也不能无理由静音关键吼叫。

## 描述范围

遵守本次 descriptionConstraints。视频描述中的发声要求与声音要求同等有效，明确范围高于自动层规划和规则回退。描述对应点位必须进入 Gemini 候选复核，排他/禁用范围下所有候选均复核；要求选材决策附 meetsDescription，未明确符合或请求失败时保留缺口，不悄悄回退到名称候选。范围外的混合录音也应拒选。最终检查每条必需点位是否有启用贴片。
